# Guess the Flag

A fun and interactive flag-guessing game built with SwiftUI. Test your knowledge of world flags by selecting the correct flag from multiple options and improve your score as you play.

## Features

- Guess countries based on their national flags.
- Choose from multiple flag options.
- Track your score as you play.
- Receive feedback on your selections.
- Enjoy a simple and interactive user interface.

## Technologies Used

- **Language:** Swift
- **Framework:** SwiftUI
- **IDE:** Xcode

## Key Learnings

- Building interactive interfaces with SwiftUI.
- Managing game state and user interactions.
- Working with buttons, images, and layout components.
- Implementing conditional logic for answers and scoring.

## Getting Started

1. Clone or download this repository.
2. Open the `.xcodeproj` file in Xcode.
3. Select an available iOS simulator.
4. Build and run the app.

## Purpose

This project was built to practice SwiftUI fundamentals, state management, and interactive app development while creating a simple flag-guessing game.
